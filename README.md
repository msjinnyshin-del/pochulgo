# AI 공유회 랜딩 페이지

각자의 현장에서 AI를 쓰는 사람들의 이야기 — 모바일 랜딩 페이지.
Claude Design 시안 3안 중 **1b(페이퍼 에디토리얼)** 안을 배포용으로 구현한 정적 페이지입니다.

## 구성

```
index.html   랜딩 페이지 (단일 파일, 빌드 불필요)
assets/      이미지
```

의존성 없음. `index.html`을 브라우저로 열면 그대로 동작합니다.

## 배포

GitHub Pages로 자동 배포됩니다 (main 브랜치 루트).

## 이미지

전부 김건우 연사 채널 배너 원본에서 만들었습니다.

| 파일 | 용도 | 크기 |
|---|---|---|
| `assets/keynote-banner.jpg` | 키노트 배너 (AX PLAYBOOK) | 1600 × 265 |
| `assets/speaker-kimgunwoo.jpg` | 김건우 프로필 (배너에서 얼굴 크롭) | 800 × 800 |
| `assets/og.jpg` | 카톡·SNS 링크 미리보기 | 1200 × 630 |

이미지를 교체할 때 파일이 없으면 깨진 아이콘 대신 회색 자리표시 박스가
표시되므로 페이지 자체는 계속 정상 동작합니다.
